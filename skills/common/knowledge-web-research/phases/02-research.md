# Fase 2 — Investigación

## Objetivo

Buscar información en la web, leer las fuentes, y recopilar hallazgos verificados.

## Qué hacer

### 1. Buscar fuentes

Realiza búsquedas web orientadas al tema del briefing. Usa queries específicos, no genéricos.

**Buena query:** `"OAuth 2.0 PKCE flow implementation best practices 2025"`
**Mala query:** `"OAuth"`

Haz al menos 2-3 búsquedas con enfoques diferentes para cubrir el tema.

### 2. Seleccionar fuentes fiables

De los resultados, prioriza en este orden:
1. **Documentación oficial** (RFCs, docs de la tecnología, MDN, etc.)
2. **Blogs de referencia** (Martin Fowler, Thoughtworks, ingenieros senior con nombre)
3. **Papers y artículos académicos** (arxiv, ACM, IEEE)
4. **Blogs técnicos con autor** (Medium con autor verificable, dev.to con contenido técnico)
5. **Stack Overflow** (respuestas aceptadas con alta puntuación)

**Descartar:**
- Artículos sin autor o de granjas de contenido SEO
- Contenido claramente desactualizado (>3 años salvo que sea fundamental)
- Tutoriales básicos que no aporten profundidad
- Resultados patrocinados o comerciales disfrazados de artículo

### 3. Leer y extraer

Para cada fuente seleccionada (máximo 4-5):
- Lee el contenido completo
- Extrae los puntos clave relevantes para el briefing
- Anota la URL para citar después

### 4. Contrastar

- ¿Las fuentes coinciden en los puntos principales?
- ¿Hay contradicciones? Si las hay, anótalas con las fuentes de cada posición.
- ¿Hay consenso claro o es un tema en debate?

### 5. Registrar hallazgos

Para cada hallazgo, registra:
- **Hecho/concepto**: la información concreta
- **Fuente**: URL
- **Confianza**: Alta (múltiples fuentes coinciden), Media (1-2 fuentes), Baja (solo una fuente o tema en debate)

## Criterio para avanzar

- Has consultado al menos 2-3 fuentes fiables.
- Los hallazgos están registrados con fuente y nivel de confianza.
- No hay contradicciones sin resolver (o están documentadas).

Pasa a la **Fase 3 — Síntesis**.
