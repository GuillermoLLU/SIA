      Nueva clave

      SIA guarda el conocimiento (RAG), las skills, los grupos y los enlaces en un proyecto de Supabase tuyo o de tu equipo. Puedes conectar varias bases; cada chat trabaja contra una. Los datos se guardan solo en esta máquina.

      Tu proyecto responde, pero aún no tiene las tablas de SIA

      Se montan en tres pasos. Supabase no permite crear tablas desde una app, por eso el SQL se ejecuta a mano en su editor.

      1. 1
        Copia el SQL

        Crea las tablas, la búsqueda, las políticas de acceso y lleva tu clave de dueño recién generada.

      2. 2
        Ejecútalo en Supabase

        Pégalo en el SQL Editor de tu proyecto y pulsa Run.

        Abrir el SQL Editor ↗
      3. 3
        Verifica y termina

        Se comprueba que la base responde con el esquema completo y, si todo está, tu clave de dueño queda guardada en este equipo.
